NOAA Fisheries Integrated Toolbox

   

Tool: Age Structured Projection Model User Interface (AGEPRO-GUI)


Authors

Brodziak, J. and E. Fletcher

Description

This is a Windows-based Graphical interface of AGEPRO (Age Structured Projection Model), designed to evaluate the likely population consequences of complex harvest scenarios under alternative hypotheses about the stock-recruitment relationship. Uncertainty in initial population size at age is incorporated into the model. This GUI is a revamp of the the original NOAA Fisheries National Fisheries Toolbox interface designed by Alan Seaver. AGEPRO-GUI includes AGEPRO Calculation Engine, the command line based version of AGEPRO.

Associated Tools
