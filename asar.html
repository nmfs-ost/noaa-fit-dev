Tool: asar (asar)


Authors

Contributors

Bai Li, Kathryn Doering

Description

{asar} is an R package that partially automates a stock assessment report and facilitates actions accompanying the workflow including making documents accessible (a federal requirement). This package was developed out of a need for a more streamlined and efficient stock assessment process where the lowest hanging fruit was reporting. It standardizes report structure while simultaneously allowing broader customizations needed for a particular stock or region's report. The need to make accessible documents in an automated fashion was a top priority, so heavy development and a collaboration with Quarto, a major industry partner, brought {asar} accessibility features to an open-source publishing platform used by thousands worldwide.
