Description

The mission of the Fisheries Integrated Modeling System (FIMS) is to enhance the connection of models used to assess the status of managed fish stocks to ecosystem, climate, and socioeconomic factors while meeting current management needs. We aim to accomplish our mission with a user-friendly stock assessment tool that streamlines the development and application of scientific advice to inform current and future management needs of NOAA Fisheries’ regions. Users and developers are welcome to submit feedback using Github Issues and Discussions.

Installation Instructions

The following software is required:

  • R version 4.0.0 or newer (or RStudio version 1.2.5042 or newer)
  • the remotes R package
  • TMB version 1.8.0 or newer (install instructions are here.)
  • Rtools4 (required for Windows users only; available from here)
Install using: 
remotes::install_github("NOAA-FIMS/FIMS")
library(FIMS)
